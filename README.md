This code computes the flow fields based on this paper:
Choudhury, Anjishnu, et al. "On the role of viscoelasticity in mucociliary clearance: a hydrodynamic continuum approach." Journal of Fluid Mechanics 971 (2023): A33.
Equations (4.1a,b), (4.2), (4.3a), (A1a–d), and (A3a–d) are solved to obtain the flow field U=(u,v) where u is the flow along x-axis, while v denotes the flow along y-axis.
The domain is discritized in a square grid and the output can be saved in a excel or csv for visualizations.
